# 명예 외국인 — 기능정의서

**기준일:** 2026-10-07
**대상:** 저장소 `main` 브랜치에 구현·배포된 기능
**근거:** `docs/superpowers/specs/`의 설계 문서, 커밋 기록, 현재 코드

설계 과정과 선택 이유는 [의사결정과정 문서](decision-log.md)에 따로 정리했다.

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 명예 외국인 |
| 형태 | PWA (홈 화면 설치, 오프라인 열람) |
| 목적 | 일상 회화 표현을 하루 1개씩 꾸준히 접하고, 게임과 맞춤 설명으로 능동적으로 익히게 한다 |
| 대상 | 한국인 영어·일본어 학습자 (중급~중고급 일상 회화) |
| 언어 트랙 | 영어 / 일본어 (화면 상단 토글로 전환) |
| 디자인 | 픽셀아트, 파스텔 코지 톤 |
| 계정 | 없음. 개인 설정은 기기 `localStorage`에만 저장 |

### 1.1 시스템 구성

```
[GitHub Actions]
  매일 00:00 KST  단어 생성(영·일) → 영어 벡터 색인 → 커밋
  main push       앱 빌드 → GitHub Pages 배포
  매주 월 08:00   Claude 트렌드 메일 발송

[GitHub Pages]     정적 앱 + 단어 JSON (API 키 없음)
        │ 맞춤 설명 요청
        ▼
[Cloudflare Worker] grow-up-everyday-explain
  ├ KV RATE_LIMIT       IP별 일일 요청 수
  ├ Vectorize en-words  영어 단어 벡터
  └ OpenAI              설명 생성
```

## 3. 기능 상세

### F-01 오늘의 단어

- **설명:** 하루에 단어·표현 1개를 카드로 보여준다.
- **영어 필드:** 단어, 한글 발음, 뜻, 예문, 예문 번역 (품사는 화면에서 제거)
- **일본어 필드:** 단어(한자), 히라가나 읽기, 한글 발음, 뜻, 예문, 예문 한글 발음, 예문 번역
- **생성 규칙**
  - 매일 00:00 KST에 GitHub Actions가 OpenAI로 생성한다.
  - 최근 90일 동안 나온 단어는 다시 내지 않는다.
  - 오늘 단어가 이미 있으면 생성을 건너뛴다.
  - 필수 필드가 빠진 응답은 버린다.
- **오늘 판별:** 기기 날짜의 파일을 찾고, 없으면(생성 전·시간대 차이) 아카이브에서 가장 최근 단어를 보여준다.
- **NEW 배지:** 마지막으로 본 날 이후 새 단어가 생겼으면 표시한다. 언어별로 따로 기록한다.

### F-02 아카이브

- 지금까지 나온 단어 목록(날짜·단어·뜻)을 보여주고, 항목을 누르면 상세 카드를 연다.
- 탭 이름에 현재 언어의 단어 개수를 표시한다. 예: `아카이브 (73)`
- 목록은 가벼운 인덱스 파일 하나로 그리고, 상세 데이터는 열 때만 받는다.

### F-03 언어 토글

- 화면 최상단의 `영어 | 일본어` 버튼으로 전체 화면을 전환한다.
- 탭 선택 상태는 유지한다. 단, 일본어로 바꿀 때 빈칸 게임 탭에 있었다면 오늘의 단어 탭으로 이동한다.
- 언어별 상태(마지막으로 본 날, 표시 중인 단어, 학습자 프로필)는 서로 섞이지 않게 따로 저장한다.

### F-04 발음 듣기

- `🔊 단어 발음`, `🔊 예문 발음` 버튼을 누르면 브라우저 음성합성으로 읽어준다 (영어 `en-US`, 일본어 `ja-JP`).
- 버튼을 다시 누르면 이전 재생을 멈추고 새로 읽는다.
- 챌린지 진행 중에는 예문 발음 버튼을 숨긴다 (정답 노출 방지).
- 음성합성을 지원하지 않는 브라우저에서는 버튼을 표시하지 않는다.

### F-05 일본어 한글 발음 표기

- 단어와 예문의 히라가나를 한글로 표기한다. 예: `[けいけん] 케-켄`
- LLM이 아니라 가나→한글 변환 규칙(`scripts/kanaToHangul.mjs`)으로 만든다.

### F-06~F-08 예문 챌린지 (영어)

"다른 단어 보기"를 누르면 세 유형 중 하나가 무작위로 나온다. 통과하면 아카이브의 다른 단어로 넘어가고 축하 연출이 나온다.

| ID | 유형 | 방식 | 정답 기준 | 오답 처리 |
|---|---|---|---|---|
| F-06 | 타이핑 | 숨겨진 영어 예문을 입력 | 앞뒤 공백·대소문자 무시, 문장부호는 정확히 일치 | 내 답과 정답을 나란히 보여주고 재시도 |
| F-07 | OX 퀴즈 | 단어와 뜻이 맞는지 O/X 선택 | 50% 확률로 다른 단어의 뜻을 섞음 | "땡!" 표시, 같은 문제로 재시도 |
| F-08 | 순서배치 | 섞인 단어 조각을 순서대로 탭 | 원래 순서와 정확히 일치 | 처음 상태로 되돌리고 재시도 |

- **공통 규칙**
  - 진행 중에는 예문을 숨긴다. 한국어 번역은 힌트로 남긴다.
  - 연습할 다른 단어가 없으면 버튼을 비활성화하고 안내 문구를 보여준다.
  - "오늘의 단어로" 버튼은 다른 단어를 보고 있을 때만 나타난다.

### F-09 예문 챌린지: 음성인식 (일본어)

- 🎤 버튼을 누르고 예문을 소리 내어 말한다 (Web Speech API, `ja-JP`).
- **정답 기준:** 가타카나를 히라가나로 바꾸고 구두점·공백을 지운 뒤, 한자 섞인 예문이나 히라가나 읽기 중 하나와 일치하면 정답.
- **오답:** 내가 말한 문장과 정답을 나란히 보여주고 재시도할 수 있다.
- **미지원 브라우저**(Firefox 등)에서는 "Chrome/Edge로 접속해주세요" 안내만 보여준다. 타이핑으로 대신 푸는 방법은 없다.
- **한계:** 오쿠리가나 차이나 다른 한자 표기는 인정하지 않는다.

### F-10 빈칸 게임 (영어)

- 별도 탭이다. 아카이브 단어의 예문에서 단어 자리를 비워두고 입력하게 한다.
- 점수와 연속 정답 수를 보여준다.
- 단어마다 예문 3개를 미리 생성해 두어, 같은 단어라도 다른 문장으로 나온다.
- 일본어 모드에서는 탭을 숨긴다. `src/pages/JaGamePage.tsx` 파일은 있지만 연결되지 않아 사용되지 않는다.

### F-11 내 수준 맞춤 설명 (채팅)

- **진입:** 오늘의 단어 카드의 `💡 내 수준에 맞게 설명` 버튼. 챌린지 진행 중에는 숨긴다.
- **학습자 프로필** (첫 사용 때 입력, 언어별 저장)
  - 일본어: 히라가나 / 가타카나 / 한자를 아는지, 메모
  - 영어: 수준 3단계, 발음기호를 읽을 수 있는지, 메모
- **대화**
  - 첫 설명 1회 + 후속 질문 최대 5회
  - 질문은 최대 200자
  - 추천 질문 버튼 제공 (예: "비슷한 표현 알려줘")
- **설명 범위:** 뜻, 발음, 용법, 문법, 예문, 비슷하거나 반대인 표현, 전에 배운 단어와의 비교. 학습과 전혀 상관없는 요청(코딩, 잡담 등)만 거절한다.
- **오류 안내**

| 상황 | 안내 문구 |
|---|---|
| 하루 한도 초과 (429) | 오늘 질문을 다 썼어요 |
| 서버 오류 (5xx) | 잠깐 문제가 생겼어요 + [다시 시도] |
| 오프라인 | 인터넷 연결이 필요해요 |

- **보호 장치 (Worker)**
  - 허용된 출처(`subeen2.github.io`, `localhost:5173`)에서 온 요청만 받는다.
  - 요청 크기는 48KB까지, 필드별 길이 제한이 있다.
  - IP당 하루 30회로 제한한다.
  - OpenAI 호출은 15초가 지나면 중단한다.
- **표시:** 응답은 일반 텍스트로만 보여준다 (HTML·마크다운 렌더링 안 함).
- **설정 조건:** 앱 빌드 변수 `VITE_EXPLAIN_API_URL`이 비어 있으면 패널을 보여주지 않는다.

### F-12 관련 단어 검색

F-11의 프롬프트에 "학습자가 전에 배운 단어" 최대 5개를 넣는 검색 단계다.

| 언어 | 방식 | 실패 시 |
|---|---|---|
| 일본어 | 같은 한자를 공유하는 과거 단어. 공유 한자가 많은 순, 같으면 최신순 (클라이언트) | 한자가 없는 단어는 관련 단어 없음 |
| 영어 | 뜻이 비슷한 과거 단어를 벡터 검색 (Worker) | 최근 단어 5개로 대체 |

- **영어 색인**
  - 매일 단어 생성 직후 영어 아카이브 전체를 `text-embedding-3-small`로 임베딩해 Cloudflare Vectorize `en-words`에 저장한다.
  - id는 날짜, metadata는 단어와 뜻이다.
- **영어 검색**
  - 오늘 단어의 벡터로 가까운 단어 6개를 찾고, 자기 자신을 빼서 5개를 쓴다.
  - 1.5초 안에 답이 없거나 오류가 나면 클라이언트가 보낸 최근 5개를 쓴다.
- **실제 결과 예:** `call it a night` → `call it a day`(유사도 0.83), `wrap up`, `throw in the towel`, `call off`

### F-13 새 단어 알림

- 🔔 버튼으로 알림 권한을 요청한다.
- Android Chrome에 설치된 PWA에서만, 주기적 백그라운드 동기화가 지원되면 새 단어가 생겼을 때 알림을 보낸다.
- 그 밖의 환경(iOS 포함)에서는 앱을 열 때 NEW 배지로 대신한다. 정해진 시각에 알림이 온다고 보장하지 않는다.

### F-14 사용성 보조 기능

- **이어보기:** 앱을 다시 열면 마지막으로 보던 단어를 보여준다. 날짜가 바뀌어 새 단어가 생겼으면 오늘 단어가 우선한다.
- **당겨서 새로고침:** 화면을 아래로 당기면 새로고침한다. 입력창에서 시작한 터치는 가로채지 않는다.
- **축하 연출:** 챌린지에 통과하면 애니메이션을 보여준다.
- **오프라인:** 앱 화면과 이미 받은 단어 데이터는 오프라인에서도 볼 수 있다 (서비스워커 캐시).

### F-15 주간 Claude 트렌드 메일 (운영 자동화)

- **실행:** 매주 월요일 08:00 KST, GitHub Actions
- **수집**
  - `claude.com/ko/blog` 새 글
  - `anthropics/claude-code` CHANGELOG 새 버전
  - 이미 본 항목은 `data/trend-state.json`으로 걸러낸다.
- **요약:** OpenAI가 Cowork·Claude Code 관련 항목만 골라 한국어로 요약한다. 링크는 LLM이 아니라 수집한 데이터로 붙인다.
- **메일 구성:** 이번 주 핵심 3줄 / Cowork 소식 / Claude Code 소식 / 트렌드 해석. Resend로 발송한다.
- **실행 규칙**
  - 관련 소식이 없으면 보내지 않는다.
  - 발송에 성공한 뒤에만 state를 갱신한다.
  - 첫 실행은 최근 5개 글과 3개 버전만 다룬다.
- **상태:** 코드는 배포됐지만 `RESEND_API_KEY`, `DIGEST_TO_EMAIL` secret이 아직 등록되지 않아 발송 전이다.

## 5. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 비용 | GitHub Pages, Actions, Cloudflare 무료 플랜 범위. OpenAI는 소형 모델만 사용 |
| 보안 | API 키는 GitHub Secrets와 Worker secret에만 저장하고 클라이언트에 노출하지 않음 |
| 남용 방지 | 출처 검사, IP당 하루 30회, 요청 크기·필드 길이 제한 |
| 장애 격리 | 한 언어의 데이터 문제나 벡터 검색 실패가 다른 기능을 막지 않음 |
| 접근성 | native 폼 요소, 채팅 메시지 `aria-live`, 토글 `aria-pressed` |
| 테스트 | Vitest + Testing Library, 43개 파일 291개 테스트 |
